# Security Policy

## Supported Versions

| Version | Status |
| ------- | ------ |
| v1 | ✅ Supported |

**macREC v1** is the currently supported version and receives security updates. However, it has **not been tested for use in real exams**.

## Reporting a Vulnerability

If you find a security vulnerability in macREC, please report it using one of the following channels:

- **GitHub Issues:** Open an issue in this repository.
- **Contact form:** [niklaslegler.at/contact](https://niklaslegler.at/contact)

Please describe the problem as precisely as possible (affected version, steps to reproduce, potential impact). For security-sensitive details, please use the contact form instead of a public issue so the vulnerability is not disclosed before it has been fixed.
